# אפליקציית ניהול קופונים אישית (RTL)

מערכת אישית לניהול קופונים בעברית מלאה ו־RTL, עם התחברות מאובטחת, דשבורד, סינון, התראות מייל ותזמון יומי.

## התקנה

```bash
npm install
cp .env.example .env
npm start
```

## דרישות
- PostgreSQL פעיל
- Node.js 18+

## פיצ'רים עיקריים
- הרשמה/התחברות (משתמש יחיד)
- CRUD מלא לקופונים
- סטטוס אוטומטי לפגי תוקף
- סימון ידני כ"מומש"
- סינון, חיפוש, מיון לפי תפוגה
- דשבורד סטטיסטיקות + גרפים
- משימת Cron יומית (08:00) לתזכורות תפוגה בעוד 7 ימים
- מניעת תזכורות כפולות באמצעות טבלת `coupon_reminders`

## אבטחה
- Hash לסיסמאות עם bcrypt
- שאילתות פרמטריות למניעת Injection בסיסי
- ניהול session + CSRF
